# Security Policy

## Supported Versions

This project is provided as a portfolio and research artifact. Security patches are provided for the latest version only.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly. Do NOT open a public GitHub issue.

**Contact:** andre.obiuzo@gmail.com

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested remediation (optional)

You will receive an acknowledgment within 48 hours, and a detailed response within 5 business days.

## Scope

This policy covers:
- Prompt injection vulnerabilities in the evaluation framework itself
- Code execution or data exposure risks in the sandbox environment
- Dependency vulnerabilities in requirements.txt

Out of scope:
- Vulnerabilities in the LLM models being tested (report to the model provider)
- Attack scenarios that are deliberately tested as part of the evaluation framework
